# Quarter-zip colour showcase

The homepage uses the catalogue's colour names, swatches and cover photos. When the showcase is idle, the garments appear in pairs. The Burgundy studio turn uses a sequence of generated views based on the owner's front, collar and back photos. The other colours use their photographed fronts.

Hover, keyboard focus or a tap shows the original product photograph. Moving the mouse off the list returns to idle after 300 ms. Escape, a second tap on the same colour, or tapping outside clears the preview. Reduced-motion users see a static arrangement. Product pages show the original galleries.

## Adding a colour

Add the product and its images using the instructions in [the product image guide](../public/images/products/README.md). Set the colour name and artColor swatch, and list the main photo first. The homepage updates the colour list, count and description from the catalogue. In backend mode it uses approved catalogue images.
